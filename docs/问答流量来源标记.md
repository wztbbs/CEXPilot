# 问答流量来源标记

`POST /api/ask` 和 `POST /api/ask/stream` 均接受可选布尔字段 `isRealUser`：

```json
{
  "question": "币安 BTC/USDT 永续现在多少钱？",
  "isRealUser": false
}
```

省略、`null` 或 `true` 均按真实用户流量标记；只有显式 `false` 标记为脚本流量。现有前端和旧 Java 调用无需修改。标记属于每次请求，不从会话继承，只写入 trace，不改变会话选择、路由、提示词、规划和执行。

数据库列为 `ask_trace.is_real_user`：true 表示用户流量标记，false 表示脚本流量标记，NULL 表示历史来源未知。`/api/trace/{id}`、`/api/trace_detail/{id}` 和 `/api/traces` 的 trace 对象会返回该字段，名称为 `is_real_user`。这只是调用方提交的统计标记，不代表用户身份验证。

## 部署

- 新库使用更新后的 `db/schema.sql`，列定义为 `BOOLEAN NULL DEFAULT TRUE`。
- 存量库在部署新版应用前，手动执行一次 `src/main/resources/db/migrations/020_trace_real_user.sql`。
- 迁移先添加默认 NULL 的列，再将未来插入的默认值改为 TRUE，不回填已有行；历史记录保留未知。
- 当前 schema 初始化是 `CREATE TABLE IF NOT EXISTS`，不会自动修改现有表，不能只重启应用代替迁移。

此次不修改测试脚本。后续脚本可传 false；独立用例仍需独立会话，多轮用例只在同一用例内部复用会话。此标记不负责隔离上下文。同会话忙碌或在建 trace 前被拒绝的请求沿用原有行为，不额外创建 trace。
