# 现货行情接入

现货复用 `price.*`、`trade.*`、`orderbook.*`、`taker.*` 指标名，产品由 `instrument.market_type` 区分。当前支持 USDT 报价现货（`spot`）与 USDT 报价、USDT 结算永续（`perpetual`）。新任务未指定市场时沿用永续默认；多轮追问继承市场，明确切换市场时重新校验能力。

## 配置和接口

```yaml
exchange:
  binance:
    base-url: ${BINANCE_BASE_URL:http://43.160.213.63:18080}
    spot-base-url: ${BINANCE_SPOT_BASE_URL:http://43.160.213.63:18082}
  okx:
    base-url: ${OKX_BASE_URL:http://43.160.213.63:18081}
```

Binance 现货只请求独立的 `spot-base-url`（上游 `data-api.binance.vision`），不复用 `/fapi` 上游。OKX 共用客户端，现货品种为 `BTC-USDT`，永续为 `BTC-USDT-SWAP`，请求继续携带 User-Agent。

| 指标 | Binance 现货 | OKX 现货 |
|---|---|---|
| 最新成交价、官方 24h 涨跌幅、基础币成交量、真实报价币成交额 | `/api/v3/ticker/24hr` | `/api/v5/market/ticker` |
| 区间 OHLC、涨跌幅、基础币成交量、真实成交额、价格/成交量序列 | `/api/v3/klines` | `/api/v5/market/candles`、`history-candles` |
| 买一、卖一、价差、挂单不平衡度 | `/api/v3/depth` | `/api/v5/market/books` |
| 区间主动买量、主动卖量、主动买占比 | 5m K 线总量、主动买量字段；卖量=总量−买量 | 暂未接入交易对级统计，不用币种级汇总代替 |
| 资金费率、OI、标记价、指数价 | 不开放现货绑定 | 不开放现货绑定 |

## 计划、能力与路由

目录路径保留 `src/main/resources/metrics/cex-perpetual.yml`，内容升级为 `cex-market-v2`。绑定层级为 **指标 → 市场 → 查询形态 → Provider/selector/交易所/参数约束**，各市场的能力独立呈现给 Planner，不能把交易所或形态取并集。

例如 `trade.turnover_24h` 的现货绑定支持两所；永续绑定仍只支持 Binance。所有算子保持原有输入契约，可引用不同指标组完成现货与永续比较，不新增同义的现货指标或算子。

```json
{
  "metrics": [{
    "id": "spot_price",
    "metric": "price.last",
    "exchanges": ["binance", "okx"],
    "instrument": {"market_type": "spot", "base": "BTC", "quote": "USDT"},
    "query_shape": "snapshot"
  }],
  "calculations": []
}
```

现货不使用合约结算币，必须省略 `settle`；永续省略时补 USDT。编译产物、事实身份、会话查询状态和监控保存的 DAG 均保留市场类型。历史现货与永续事实不可互相复用。监控仍要求同一交易所、同一市场、同一品种；展示文案按实际产品生成。

## 口径和时间

- OKX 现货 ticker 的 `vol24h` 是基础币量、`volCcy24h` 是报价币额；永续字段口径不同。现货 K 线基础币量取索引 5，永续取索引 6；真实报价币额均取索引 7。
- Binance 现货 K 线单页上限 1000，永续维持 1500。分页、自动粒度和预算检查按市场使用对应能力；不完整统计不输出 value。
- OKX 历史分页沿用 `before` 下界、`after` 上界；现货近期与历史请求均保留现货品种。
- Binance REST 现货盘口不带交易所数据时间。结果提供 `collected_at`、`timestamp_source=local_collection` 和缺失原因，不伪造 `as_of`。回答只能称其为采集时间；持续监控对这类快照按采集时间检查过期，不代表已核实交易所数据的新鲜度。
- Binance 现货 taker 使用固定 5m K 线，未完结周期由覆盖校验排除；不把部分 K 线量当成完整周期统计。

目录指纹随本次改动变化。现有历史事实及已确认监控仍按原有版本校验规则处理；旧版监控需重新生成并确认，避免静默切换指标口径。

## 验证

`SpotMarketFlowTest` 使用本机 HTTP 模拟交易所，贯通 Planner 协议、真实目录、编译、Provider、HTTP 参数/报文解析和确定性算子，同时验证市场切换、历史事实隔离、监控持久化与执行。分页测试单独验证 Binance 现货 1000 条分页和 OKX 现货历史/近期路由，配置测试验证两个币安地址独立绑定。

测试不请求线上问答或发送邮件；线上回归脚本仍须按 AGENTS.md 得到明确执行指令。
