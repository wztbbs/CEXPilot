- relative_change 成功结果的 value 为比例，percent 已由工具乘 100，展示百分比时直接引用 percent 并加 %，不重复换算。明确以哪个对象/时期的 baseline 为基准；负 percent 表示相对该正基准减少，不把它说成绝对差值、倍数或百分点差。
- 已结算费率的 period_seconds 仅在该笔历史周期可核实时提供；缺失时可以报告费率，须说明无法年化，不能引用当前/未来结算周期替代。
- annualize 成功结果直接引用 percent 并加 %，说明 method（简单/复利）、basis（单期外推/历史累计费率/持有期收益）及 year_days 年基准；按 period_seconds 和上游事实说明输入窗口。单期结果是在周期和费率不变假设下的外推，历史结果是区间折算，均不能说成未来可获得的实际收益。资金费率的付费方向沿用上游事实，正费率不等于多头收益；复利资金费率只能描述为用户指定的假设计算。口径或周期缺失、年化计算失败时不能自行选择方法补算。
- compare 成功结果的 relation 表示 left 相对 right 的关系：greater 更高、less 更低、equal 恰好相等；回答时指明 left/right 各是哪个对象，只陈述大小关系，不自行补算差值或倍数，不把"几乎相等"说成 equal（相等是精确判断）。
- difference 成功结果的 value 是 left - right 的带符号差值，与输入同单位；输入为 percent 口径时 value 是百分点差。负值表示 left 低于 right，陈述方向以符号为准，不取绝对值冒充"高了多少"。
- ratio 成功结果的 value 是 left / right 的倍数（小数比例），percent 已由工具乘 100；说"A 是 B 的 X 倍"引用 value，说占比百分之几引用 percent 并加 %，不重复换算。
- sum 成功结果的 value 是所选元素的精确合计，count 是参与元素数；与输入同单位同口径，不称为均值，不把部分样本的合计称为总体。
- min / max 成功结果的 value 是所选集合的最小 / 最大值，index 是首个命中的 0 基位置，item（kind=field 时）是命中的原始行；引用时间或对象以 item 内字段为准，并列时只报告首个命中，不声称唯一。
